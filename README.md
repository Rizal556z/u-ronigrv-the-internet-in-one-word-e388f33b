Entry for the [make.fun](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) bounty **"The Internet in One Word"** — describe the whole internet in a single word.

## The entry

**feral**

One blunt adjective: wild, untamed, unmoderated chaos. Funny on its own, true of the internet as a whole (not one app or one mood), surprising next to the obvious words, and it lands in a single beat — five letters.

## How it works

`main.py` (pure Python standard library, no network, no secrets) validates the word against the competition gate — 1 to 30 characters, exactly one word, no whitespace — then writes it to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt   # feral
```
